# Overview

I created this Kotlin Calculator project to demonstrate and improve my understanding of the Kotlin programming language and its many features. I also wanted to develop a useful application that allows users to perform different mathematical calculations through a simple, interactive interface.

The calculator opens in a small desktop window with a number display and clickable buttons. Users can perform addition, subtraction, multiplication, division, square roots, squares, reciprocals, and percentage calculations. The application also includes decimal input, a positive/negative toggle, backspace, Clear (C), Clear Entry (CE), and an Answer (ANS) button for recalling previous results.

Additionally, the calculator provides a calculation history that users can view or clear. I implemented error handling to prevent invalid operations, such as division by zero or attempting to calculate the square root of a negative number.

My main purpose in developing this software was to learn Kotlin through hands-on programming while creating a functional application. I wanted to understand not only how to write the code, but also why different programming concepts and structures are used.
